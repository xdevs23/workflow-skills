# One decision path, recorded once

Review the change through one lens: one decision path, recorded once.

- Report a second enforcement site for a rule enforced elsewhere.
- Report a parallel decision path to the same outcome.
- Report the same truth derived or recorded twice.
- Report logic copied instead of shared.
- Grep for the concept, and stay with the change and what it touches, never the whole product or
  work merged before it.
- Leave alone two sites that encode genuinely different decisions.
- Cite both sites of every finding, and say which should be the single path.
