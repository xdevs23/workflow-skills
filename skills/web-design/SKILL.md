## Choices

- Shape layout of web page itself from idea of page. Layout that fits any other subject unchanged
  looks generic
- Shape navigation and page header of web page from idea of page too
- Keep navigation recognizable as navigation at first glance. Name each place it leads to in
  words, so reader knows target before pressing
- Never build page on stock frame: wordmark top left, links and button top right, large headline
  with button under it, then row of sections
- Choose placement and shape of header, navigation, actions and every other part from topic and
  use case of page. Never take them from habit or from other pages
- Never reach for part used by habit on every page, e.g. wavy edge between sections or expandable
  questions at end. Take form of each part from idea of page

## Scenes

- Make page extravagant. Let one bold idea fill first screen and come back down page, rendered
  with light, material and depth or composed boldly in colour and shape. Timid flat drawing,
  diagram or plain copy of everyday object = tame page
- Render subject in 3D where it is thing of real world or object to handle and audience enjoys
  seeing it. On page with abstract subject, keep 3D small: one object beside text of first screen,
  at most small objects above headings of sections
- Render material named by page so that it reads as that material at first glance. Choose other
  kind of visual where render falls short of that
- Build motif from material of subject itself
- Give each screen height one idea, with large empty areas. Keep first screens almost empty. Let
  detail, lists, forms and tables come later down page
- Build first screen around one bold idea made from motif of page: scene or object. Never let
  text carry first screen as picture. Never put sentence under main headline. Put its fact into
  section further down
- Never write headline for first screen only to have text there. Where page has brand name, set
  brand name there, in treatment taken from idea of page, at size that eye reads as one word.
  Otherwise leave headline out
- Keep text of first screen moderate in size, brand name included. Never let text, or picture
  built around text, span whole width of window
- Put each line of text in part whose subject it states. Never place line beside first screen
  where it relates to nothing around it
- Never stack headline, sentence and button in one column
- Pick at most one or two of these, only where idea of page calls for them. Leave out the rest:
  - one protagonist taken from subject travelling through sections of page, so scroll reads as one
    journey, each screen height entering next scene as camera moving into it
  - picture breaking out of frame drawn around it
  - fine measuring marks over scene: hairline grid, crosshairs, thin frame around title
  - collection of items shown as objects set in space for reader to pick up
- Run key scenes edge to edge. Keep reading text in narrow column beside visual
- Make page read as one whole: one palette, one style of drawing, one set of faces in every
  section
- Give every section composition of its own. Change lightness or surface between sections,
  within palette of page, with shaped or hard edge, never by slight change of tint
- Never draw section edge as large rounded corner with coloured line along it
- Keep edge between sections smooth. Never draw it with sharp points or steps
- Leave section out where content does not need one. Let two neighbouring colours blend smoothly
  where hard edge is not needed
- Keep clear gap between shaped section edge and content next to it
- Give last section full viewport height when it fills most of viewport and contrasts strongly
  with section before
- Give each edge between sections shape of its own. Never repeat one edge shape down page
- Let some parts span two or three sections: object, picture or shape that crosses edge between
  sections and ties them together. Never let page read as stack of separate bands
- Let one shape taken from subject run through containers of page
- Never leave screen height of one flat colour with few small parts on it. Break it with visual,
  layered structure or change of surface
- Set content on surface of page. Leave out bordered cards, panels and boxed tables except for one
  object that has to stand off page and for interactive object with its controls
- Put interactive object with its labels and its controls into one card set off from both sides.
  Never let label float between object and panel next to it. Size object to fit beside its panel
  within one screen height
- Give large surfaces texture where it carries idea
- Let next part peek in at bottom edge of viewport, so page asks to be scrolled
- Place wordmark, links and main action where idea of page puts them
- End every web page with footer: imprint, privacy policy, contact and other facts required by law
  of country where page is published

## Text

- Put conditions, payment, delivery, cancellation and house rules into FAQ or terms. Never on
  front page
- Give price through tool of few questions or choices that shows price of reader's case. Never
  as large table of every price
- Show each fact once on page. Never repeat in table what tool beside it already shows. Give freed
  section to fact reader wants, e.g. experience or story of business
- Name offer of page by what reader gets, in words of this page. Never by generic noun of trade
  carried over from other pages
